# v1.3.1 후보 대체

v1.3.0 소스 `068b3b6`의 운영 실행에서 이미 발행된 한국어 판을 다시 생성하는 경로를 관찰했다. 실제 정답 변경 여부는 확인되지 않았고, 정답 보존을 보장하기 위해 게시 전에 실행을 취소했다. 두 작업의 이미지와 보호 태그는 기존 상태로 복구했으며 Hosting 버전 `d8154d72cb55193f`와 기존 세 마켓 v1.2.0은 바뀌지 않았다. 복구 후 기존 health 실행도 통과했다.

실패 후보와 기존 개발 통과 기록은 보존한다. v1.3.0 태그를 이동하거나 재사용하지 않고 보존 수정과 독립 실행 후 v1.3.1의 새 후보, 코드와 태그를 발급한다. 이는 승인된 공개 출시의 실패 후보 대체이며 국가, 가격, 기능 정책과 SDK 범위를 바꾸지 않는다. 기존 화면 검수 3회는 보존하고 새 회차를 시작하지 않는다. 새 최종 SHA로 전체 기능 회귀와 서비스 검증을 다시 실행한다.

서비스는 기존 발행 슬롯과 JSON 원문 및 유효한 정답 이력을 보존하고 누락 슬롯만 생성한다. 게시 단계에서도 이미 발행된 기존 판과 언어별 JSON 교체를 거부한다. 품질 기준과 단어 수는 유지한다.

## 검증 범위

이미 발행한 실제 14판, 기존 manifest와 정답 이력을 동결한 fixture에서 두 번 재실행하고 모든 기존 바이트가 유지되는지 검사한다. 이미 있는 슬롯에서 기존 생성기를 호출하면 실패하도록 경계를 대체해 호출 0회도 확인한다. 한 판만 누락된 경우와 다음 날 신규 두 판은 단위 테스트로 검사한다. 느린 기존 생성기 자체의 품질 검사를 새로 실행했다고 표시하지 않는다. 언어별 새 공급과 재실행의 동일성도 검사한다.

작성자 보완 실행은 47개 운영 테스트를 통과했다. 새 후보의 독립 L3, 중앙 단계별 검증, 빌드, 운영 게시와 마켓 제출은 별도로 기록한다. 실제 제공자 SDK와 OS 실행은 미검증이며 기기를 사용하지 않았다.

코드 리뷰에서 기존 이력의 보관 기간만 검사해 생성기의 보관 기간 설정과 어긋날 수 있는 문제를 수정했다. 생성기와 같은 정답 및 조각 이력 보관 기간의 최댓값을 검사 기준으로 사용한다. 60일과 120일 설정의 실패 재현 및 수정 후 통과를 확인했다. 운영 설정 자체는 바꾸지 않았다.
