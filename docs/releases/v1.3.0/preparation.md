# v1.3.0 공개 준비

사용자 공개 승인과 광고 지면 3개 생성 승인을 반영했다. 현재 공개 버전은 세 마켓 모두 v1.2.0이며 이 문서는 v1.3.0 공개 완료를 뜻하지 않는다.

## 소스와 검증

- 공개 계획 승인: PR453, 414ed5f419ad37bbcc4ed33cf419d6d5e7958e63
- 언어별 공급 연결: PR454, 483a2d2e2d79f2cbab96642cc6ad4952688aeec7. CI40315351726 통과, 로컬 리뷰와 공식 API 계약 대조 완료
- 기존 독립 UI 검수: 1회 실패, 2회 실패, 3회 통과를 원본과 함께 보존. 화면 구현 변경이 없어 새 회차를 만들지 않는다.
- 새 최종 후보의 독립 기능 회귀와 중앙 검증은 이어서 실행한다. 공급자 SDK와 기기 실행은 미검증이다.
- 새 전면 지면 값을 넣으면 기존의 보상형 전용 검사기가 실패함을 재현했다. 검사 계약을 두 형식으로 갱신했고 보상형 재사용, 지면 누락과 다른 앱 지면을 주입한 세 경우의 거부를 확인했다.
- Google Play 등록 검사에서 빠진 태블릿 이미지 4장을 추가한 뒤 blocker0을 확인했다.

## 운영 의존성

현재 언어별 Hosting manifest는 404다. 기존 Hosting의 전체 파일을 보존하며 공급을 게시한 뒤 실제 URL과 매일 작업을 확인해야 한다. 등록 Firebase 운영 계정의 기존 저장소에 사용자가 Writer 권한을 추가했고, API에서 태그 생성과 갱신 권한을 확인했다. 기존 보호 태그 3개와 두 실행 계정의 actAs 권한도 확인했다. 신규 IAM 변경 없이 기존 배포와 롤백 계약으로 진행한다.

Android와 iOS 전면 지면은 각각 8094375680과 4842148506이며 공급자 응답으로 생성을 확인했다. AIT 전면 지면도 사용자의 수수료 안내 확인 승인 뒤 생성됐으며 현재 공급자 등록 처리 중이다. 기존 보상형 지면은 변경하지 않았다.

## 원장

제품 원장을 초기화하고 현재 확인한 식별자와 승인 등 25항목을 통과로, 미사용 기능 5항목을 해당 없음으로 기록했다. 나머지 68항목은 미확인 상태다. 구조 검사 통과를 제품 준비 완료로 해석하지 않는다. 후보별 출시 원장은 기존 v1.2.0 바이트를 보존한 뒤 새 후보 식별자가 정해지면 분리한다. 국가, 가격과 계정은 바꾸지 않는다.

운영 Remote Config version10에 세 전면형 ID를 연결하고 GET으로 대조했다. 기존 9개 값과 condition은 보존했다. AIT 공급자 등록 처리 중 상태와 실제 SDK 미검증을 유지한다.
