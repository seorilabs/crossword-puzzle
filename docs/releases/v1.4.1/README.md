# v1.4.1 연속 플레이와 세 마켓 출시

구현과 검수는 완료했으며 세 마켓 전체 공개는 진행 중이다. [현재 상태와 남은 단계](release-status.md), [마켓별 원장](market-launch-state.json)을 확인한다.

출시 후보는 `171d4f18726df918bf3be62c97d881e60d83610d`, 태그는 `v1.4.1`이다. 기록을 위한 이 문서 커밋은 배포 후보를 바꾸지 않는다. 버전과 빌드는 중앙 태그 receipt가 정본이며 Android `1001001019`, Apple `1004001`이다.

[승인 설계](../../design/2026-10-31-continuous-play/design.md)와 [L3 개발 환경 계획](../../design/2026-10-31-continuous-play/test-plan.json)의 공개 끝 지점을 따른다. Play는 한국 무료 배포와 전체 출시를 유지하고, App Store는 기존 5개국 무료 배포를 유지한다. 실제 기기와 실제 광고 SDK 노출은 검수 근거로 기록하지 않았다.

Issue #464는 세 마켓에서 해당 후보의 공개가 모두 확인되기 전까지 닫지 않는다. 심사 접수, 승인과 공개는 별도로 기록한다.
