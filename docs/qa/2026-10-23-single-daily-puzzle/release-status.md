## 고정 후보와 개발 검수

- 제품 source: `1cece06bb64e90ffba7b2406bccab6ac4baa84d6`, 태그 `v1.2.0`. 중앙 원장 실행 `39970717731`로 Android `1001001014`, iOS `1002000`을 발급했다.
- 독립 UI 3회는 원래 실패, 차단, 통과 판정과 시간을 보존한다. 마지막 회차는 전체 17개 UI 기능과 UX, 기본 65개와 별도 사전 계획한 3개를 합친 68개를 통과했고 실제 화면 134개를 확인했다. 첫 회차 4개 결함과 두 번째 회차의 430px 측정 문제를 실제 후속 실행으로 해소했다.
- 서비스는 같은 날짜와 seed, 초기 이력, 양쪽 samples=30으로 30일씩 실제 CLI를 실행했다. 기존 평균 19.0667단어와 초중급 15.1877%에서 개선 평균 20.6단어와 초중급 74.2259%로 바뀌었다. 원본 24,963개와 모든 후보의 양수 추첨, 보드 품질 및 신규성 검사를 보존했다. 사전 어휘 등급은 실제 이용자의 체감 난이도와 구분한다.
- 최신 중앙 `a43f2c401855f23171a4a759beb277950928505e`에서 네 대상의 세 단계, 총 12개 실제 출시 검증이 통과했다. GitHub Release의 노트와 개발 근거 13개를 내려받아 바이트가 같은지 확인했다.
- 승인 계획대로 기기와 실제 인증 및 광고 SDK, OS 동작 검수는 미실행이다. 개발 환경 실행과 macOS Foundation 검사를 해당 검수로 바꾸어 기록하지 않았다.

iOS의 실패 실행 39971842702와 39977617339는 보존했다. 두 번째 실행에서 변수 전달과 이름 검사는 통과했고, CI 프로파일의 Game Center 권한 누락으로 archive가 실패했다. 기존 등록 원본과 Apple ACTIVE 프로파일의 내용이 같고 해당 권한이 있음을 확인했다. 새 키나 프로파일 생성 없이 암호화 백업과 로컬 및 BeeStation 복원 검증을 통과한 뒤 정확한 앱의 app-store 환경 실행 복사본만 동기화했다. 앱 source와 태그는 유지한다.

공식 사이트 PR [seorilabs-official#90](https://github.com/seorilabs/seorilabs-official/pull/90)의 제품 전용 개인정보 문서는 배포 성공과 한국어 및 영어 공개 URL HTTP 200을 확인했다. App Store 초안 URL에 연결했다. Play의 URL은 저장 후 재로딩으로 확인했다. 데이터 보안은 44개 응답을 보완하고 저장 뒤 내보낸 782개 항목이 준비안과 전부 일치했다. 저장 CSV SHA-256은 `509add5e15096b55046cb5290a4f15c9f386c7fdd1c7a54e26de4ce9af4de3e1`이다. 기존 90일 자동 삭제 주장을 실제 공개된 삭제 요청 안내로 맞췄다. Play 소개와 이미지 5개의 API 및 실제 다운로드 해시는 모두 원본과 같았다. Play의 기존 production 국가 KR, Apple의 KOR와 새 국가 자동 추가 false를 확인했다. 새 언어와 국가는 출시하지 않는다.

Play 러너 수정은 core 701개, 운영 20개와 전체 CI 39987591424 및 미해결 thread 0개를 확인한 뒤 `d81564419f2f0429f89b539ffb08ae4cf7577410`으로 병합했다. MiniMax 리뷰는 40단계 제한과 허용된 재시도의 10분 시간 제한으로 보고서를 얻지 못했다. 작업 트리는 바뀌지 않았고 원인과 최종 자체 검토를 PR에 기록했다. 새 Cloud Build `52d45c56-fb22-4042-8391-9417b22e5b71`의 source 1cece06과 v1.2.0을 실제 조회했다. 산출물과 업로드 성공을 뜻하지 않는다.
