# 단일 판과 어휘 선택 실행 기록

승인 설계는 `docs/design/2026-10-23-single-daily-puzzle`이며 실행 티켓은 #435다. 앱 UI와 생성기는 별도 후보에서 개발하며, 실제 서비스 전환은 세 마켓의 새 클라이언트 공개를 확인한 뒤 다음 날짜부터 적용한다.

전체 24,963개 워드뱅크와 정답 지문을 보존한다. 추첨 가중치는 초급 128, 중급 32, 고급 및 등급 없음 1이다. 생성 탐색에서도 익숙한 단어에 점수를 더하며, 후보 자격과 정답 90일, 어근 14일 중복 제한, 교차와 밀도 등 품질 조건은 유지한다.

첫 비교에서 익숙한 어휘 추첨만 바꾼 후보는 18단어에 머물러 단어 수 보존 조건을 충족하지 못했다. 기존 큰 판의 30일 비교는 전부 통과했고 평균 19.07단어였다. 새 후보는 하한을 20단어로 높이고 최대 배치와 후보 탐색 범위를 넓혀 재검증 중이다. 승인 하한인 18단어를 낮추지 않는다. 결과가 확정되기 전 평균 어휘 비중 60%와 30일 안정성을 통과로 표시하지 않는다.

새 발행은 전날 생성하되 해당 날짜 자정에 공개하고, 전송 식별자는 기존 hard, h01과 YYMMDD01을 유지한다. 전환 날짜는 manifest에 보존하며 이전 날짜의 두 판 해석을 유지한다. 이미 발행한 판의 재실행은 답과 ID를 교체하지 않는다. 실제 공개 후 해당 날짜 health 검사와 자정 뒤 정기 점검을 구분한다.

구현 검증은 타임존과 날짜 경계, 전환 전후 health, 실제 Job 인자와 공개 전 대상 URL 확인을 포함한다. 클라우드 설정과 퍼즐 공개는 아직 수행하지 않았다. 최종 후보의 30일 원본, 실행 JSON과 로그는 NAS 검증 위치를 확정한 뒤 연결한다.
