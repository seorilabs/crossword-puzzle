# 승인 기록

사용자 응답: “보완 후 세 마켓 진행”.

승인 질문은 iOS UMP 제거, 이전 동의 값 정리, 비개인화 광고 유지와 사용 통계 끄기를 포함했다. 기기를 사용하지 않으며 실제 SDK 검사는 미실행으로 남긴다. 최종 후보의 독립 개발 검수 3회와 L3 전체 회귀를 거쳐 AIT, Google Play, App Store와 서비스 공개까지 진행한다. 버전 v1.2.0과 기존 출시 범위를 유지한다.

원안의 인증 하한 조정은 유지하고 광고 변경 사유를 갱신하며 analytics의 개발 환경 대체 사유를 추가했다. 원안 test-plan.json에도 같은 조정 사유를 반영한다.
