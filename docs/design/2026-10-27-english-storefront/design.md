# 영문 스토어 등록정보와 App Store 1.3.2 공개

상태: 사용자 승인 범위 기록. 기존 영문 등록정보 PR #458의 자료를 적용하는 후속 출시다. 사용자가 2026년 10월 27일 “1.3.2 공개, 미국·캐나다·호주·뉴질랜드 추가”를 선택했다. 문서 커밋 자체를 미리 보았다는 뜻으로 기록하지 않는다.

## 목적과 범위

App Store의 한국어 소개만으로는 영어 사용자가 이미 제공되는 영어 퍼즐을 알아보기 어렵다. [준비 및 검수 자료](../../qa/2026-10-27-english-storefront/README.md)의 영문 이름, 소개, 키워드와 실제 스크린샷을 적용한다. 기존 한국 출시를 유지하고 미국, 캐나다, 호주와 뉴질랜드에 공개한다. 가격은 무료로 유지한다.

| 항목 | 확정 범위 |
|---|---|
| 버전 | 중앙 태그 정본의 v1.3.2, 빌드 번호는 태그 receipt |
| 마켓과 끝 지점 | App Store 심사, 승인, 수동 공개와 국가별 조회까지 |
| 국가 | KOR 유지, USA, CAN, AUS, NZL 추가 |
| 등록 언어 | 한국어 유지, en-US, en-CA, en-AU 추가 |
| 영문 이름 | Daily Word Play: Crosswords |
| 코드 | v1.3.1 이후 게임, 저장, SDK와 운영 코드 변경 없음 |
| 다른 마켓 | 기존 v1.3.1 Play와 AIT의 승인 및 대기 기록 보존. 이번 v1.3.2 빌드와 제출 대상에는 넣지 않음 |

새 게임 화면, UI 개편, 광고 정책이나 지면, 가격과 자격증명을 추가하거나 바꾸지 않는다. 기존 한국어 저장과 공개 1.3.1의 소개 및 이미지를 보호한다. 원래 다섯 판 설계와 UI 3회 기록은 그대로 보존한다.

## 사용 흐름과 책임

영문 상품 페이지에서 영어 홈, 타일 입력과 완료 이미지를 확인하고 앱을 시작한다. 게임의 언어 선택, 날짜 갱신, 다섯 판, 완료 후 광고와 저장 정책은 기존 core와 adapter를 사용한다. 등록 문구는 app-store config, 언어와 이미지 연결은 english-localizations manifest, 버전은 중앙 원장이 맡는다. 변경할 제품 데이터나 인터페이스는 없다.

현재 공개 버전은 새 언어를 추가할 편집 상태가 아니므로 1.3.2 초안을 사용한다. 초안의 영어 메타데이터와 이미지가 준비되고 새 빌드 검증을 통과하면 심사에 제출한다. 수동 공개와 새 4개국 추가는 영어 등록정보가 승인된 뒤 수행한다. 기존 1.3.1은 그동안 한국에서 유지한다. 업로드 또는 처리 오류는 원인을 기록하고 동일 대상의 상태를 읽은 뒤 재시도하며 다른 키, 앱이나 태그로 대체하지 않는다. 공개 원본을 삭제하거나 제출을 임의 취소하지 않는다.

## 검증과 인수조건

| 조건 | 기준과 실행 |
|---|---|
| AC-1 | ko, en-US, en-CA, en-AU의 제목, 부제, 소개, 키워드, 개선 문구, 정책 URL을 원본과 저장값으로 대조 |
| AC-2 | 각 영어 언어 iPhone 3장과 iPad 3장의 처리 완료, 순서, 체크섬, 실제 이미지 내용을 확인하고 기존 한국어 이미지를 보호 |
| AC-3 | 새 후보 SHA에서 작성자 외 L3 개발 회귀. 기존 모든 기능, 두 언어 다섯 판, 입력, 오류 복구, 저장, 광고 닫힘 및 실패, 서비스 명령을 실행 |
| AC-4 | 기존 생성 300판을 현재 validator와 독립 검사로 다시 확인. 생성기 코드가 같다는 비교와 원래 생성 근거를 유지하며 새로 300판을 생성했다고 표시하지 않음 |
| AC-5 | 중앙 before-build, before-deploy와 제출 직전 app-store before-release가 실제 ok:true. UTC Z, 원본 실행 시각과 후보 SHA 결속 |
| AC-6 | 새 archive의 버전, 빌드, bundle, 서명, 개인정보 manifest와 암호화 설정을 가능한 산출물로 확인하고 미검사 범위를 기록 |
| AC-7 | 새 빌드의 처리, 내부 그룹, 제출 ID, 승인, 공개 상태를 각각 조회. 공개 후 5개국의 버전과 영문 등록정보를 확인 |

테스트 계획은 L3, dev를 유지한다. 작성자 외 실행 또는 확인된 CI를 사용한다. 새 UI를 만들지 않았으므로 이번 설계의 redesign은 false다. 기존 UI 1회 실패, 2회 실패, 3회 통과를 보존하며 새 4회를 시작하지 않는다. 회귀 실행은 이전 UI 회차를 다시 세거나 판정을 바꾸는 작업이 아니다.

기존 기반 기능의 개발 환경 대체 실행과 실제 네이티브 SDK 미실행 구분을 유지한다. 이번 변경에는 새로운 기기 전용 검증 조건이 없으며 기기 조회나 사용은 승인되지 않았다. TDD는 제품 동작 변경이 없는 등록 자료와 출시 운영에 적용하지 않으며, 실제 원본 및 저장값 비교와 개발 회귀로 검증한다. 새로운 가짜 실행이나 SDK 통과 기록을 만들지 않는다.

## 승인과 추적

사용자가 검토 가능한 자료: [PR #458](https://github.com/seorilabs/crossword-puzzle/pull/458), 소스 `87ab9852111a3ad50470ef95f28fb55bfc7929ea`. 승인 응답: “1.3.2 공개, 미국·캐나다·호주·뉴질랜드 추가”. 기존 한국을 유지하고 App Store 새 편집 버전에 영문 자료를 반영한다는 질문에 대한 답변이다.

이 문서와 같은 폴더의 test-plan은 승인된 범위의 실행 기록이며 기존 테스트를 줄이지 않는다. 원래 3마켓 계획과 v1.3.1의 Play 계정, AIT 법적 확인과 기기 승인 대기는 별도 이력으로 남긴다. 국가, 버전과 이번 App Store 공개 승인은 같은 범위의 후속 단계마다 다시 묻지 않는다. 지원팀 연락과 실제 기기 사용은 이 승인에 포함되지 않는다.
