# 영문 스토어 소개를 5개국에 제공

실행 이슈는 [#452](https://github.com/seorilabs/crossword-puzzle/issues/452)의 후속 App Store 범위다. [설계](design.md)와 [L3 dev 계획](test-plan.json)의 AC-1부터 AC-7을 그대로 적용한다. 사용자 승인 근거와 국가 목록은 설계의 승인 추적에 있다.

1. 새 후보 SHA를 고정하고 독립 L3 전체 기능 회귀 및 4언어 등록 자료를 검증한다.
2. 중앙 원장 태그와 receipt, 마켓별 출시노트를 결속한다.
3. 실제 중앙 before-build/deploy 통과 후 App Store 빌드와 업로드를 실행한다.
4. 공개 1.3.1을 보호하며 1.3.2 초안의 3개 영어 언어와 18개 이미지를 저장하고 다시 읽는다.
5. 처리, 내부 그룹, 정책과 최종 문구를 확인하고 before-release 뒤 심사 제출한다.
6. 승인 후 수동 공개와 새 4개국 추가를 실행하고 5개국의 실제 상품 페이지와 버전을 확인한다.

새 제품 로직이 없어 TDD의 실패 테스트를 만들지 않는다. 원본 및 저장값 대조, 후보 SHA의 실제 개발 회귀와 산출물 검사로 검증한다. UI 3회 원본과 실제 네이티브 SDK 미실행 구분을 보존한다. 기기 사용이나 지원팀 연락을 포함하지 않는다. 실행, PR, CI, 태그, 빌드, 업로드, 심사와 공개의 근거는 각각 출시 원장에 남긴다.
