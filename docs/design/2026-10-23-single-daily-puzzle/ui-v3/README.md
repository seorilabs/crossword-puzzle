# 음절 타일 시안

선택한 A 타일 보드의 색과 입체감을 유지하고, 전체 판을 음절 타일로 푸는 시안이다. `index.html`을 브라우저에서 열면 한국어와 영어 배치 예시를 직접 눌러볼 수 있다. 제품 코드와 계정, 실제 퍼즐 저장 데이터에는 접근하지 않는다.

## 화면과 입력

1. 타일 선택: 위에는 8×8 보드, 가운데에는 단서와 큰 답칸, 아래에는 정답 글자 수에 방해 글자 두 개를 더한 후보를 둔다. 타일을 누르면 다음 빈칸이 채워진다.
2. 오답 복구: 맞는 위치는 유지하고 틀린 위치만 비운다. 사용한 타일은 흐리게 표시하며 후보 위치는 바꾸지 않는다. 같은 글자는 필요한 수만큼 별도 조각을 제공한다.
3. 한 판 완성: 모든 단어가 맞아야 완성 화면을 표시한다. 한국어 예시는 18단어이며 첫 세 단어와 전체 완주를 구분한다.

한 글자 지우기, 단서 선택, 이전과 다음 미완료 단어 이동, 힌트, 자동 다음 단어 추천, 새로고침 뒤 이어풀기를 연결했다. 저장은 이 시안의 이름으로 시작하는 키 여섯 개만 사용한다. 상단 초기화 버튼도 해당 키만 지운다.

같은 화면 크기와 글자 설정에서는 보드의 크기와 위치, 단서 카드, 답칸, 후보 영역과 아래 버튼의 위치를 고정한다. 후보 영역은 한 줄에 최대 다섯 개씩 두 줄을 미리 확보하며 타일은 높이 57px을 유지한다. 짧은 단어도 남은 후보 공간을 유지한다. 긴 단서는 고정된 카드 안에서 스크롤할 수 있고 생략하지 않는다. 단어와 후보 수를 읽어 보드 크기를 다시 계산하던 코드는 제거했다.

출제 어휘의 전체 후보를 줄이거나 한 판의 단어 수를 줄이는 안이 아니다. 실제 생성 정책과 입력 계약은 [상세 설계](../syllable-tile-input.md)를 따른다. 이 폴더의 예시는 과거 시안의 샘플을 사용한다. 영어 22단어는 언어별 길이와 반복 글자 배치를 보기 위한 예시이며 해외 출시용 검수 콘텐츠가 아니다.

## 원본과 내보내기

- `index.html`, `styles.css`, `demo.js`: 편집 가능한 시안 원본
- `../ui-v2/sample-data.js`: 예시 보드와 단서
- `export-preview.mjs`: 스타일과 데이터를 포함한 단일 HTML 내보내기
- `artifacts.md`: 최종 렌더와 내려받을 수 있는 HTML의 NAS 위치

```sh
node docs/design/2026-10-23-single-daily-puzzle/ui-v3/export-preview.mjs /outside-repository/tile-preview.html
```

출력 파일은 덮어쓰지 않으며 저장소 밖에 만든다. 렌더와 실행 원본은 NAS에 보관하고 Git에는 넣지 않는다. 원본 HTML은 외부 폰트나 서버가 없어도 실행된다.

## 검증 범위

브라우저에서 실제 타일 버튼을 누르는 시안 점검만 수행한다. 점검 결과는 `prototype-checks.json`에 기록한다. 제품 앱 반영, 세 마켓의 동작 일치 검사, 승인된 L3 개발 환경 검수와 독립 검수 3회는 별도 작업이다. 시안 실행 결과를 제품 검수 통과로 사용하지 않는다.
