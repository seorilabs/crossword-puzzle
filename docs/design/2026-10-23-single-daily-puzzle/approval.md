기존 설계 본문의 “전면적인 아트 교체는 포함하지 않는다”와 “기존 앱의 서체, 민트 색상”은 이번 추가 시각 요청으로 변경 대상이 되었다. 기능 정책, 보상과 광고 규칙, 검수 등급과 출시 범위는 그대로 유지한다. 선택한 방향을 기준으로 화면 외형을 구현한다. 이번 요청만으로 해외 언어 콘텐츠 제작이나 새 국가 출시를 완료로 간주하지 않는다.
