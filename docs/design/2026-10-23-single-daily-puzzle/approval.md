- 승인 대상 커밋: `5f4fd115d7fbcb6be88a71b76ccfc9cd6850acd9`
- 승인 파일: 이 폴더의 `design.md`, `test-plan.json`
- 승인 일자: 2026-10-23
- 사용자 지시: “설계 문서 승인했고, 시안은 이번 기회에 개편해보면 좋겠다. 약간 게임스러운 UI를 가미해보면 어때? 이번 업데이트 후 후속으로 다른 국가도 진출하고 싶다. 감안해서 시안을 다시 뽑아봐.”
- 승인 범위: 큰 판 하나, 어휘와 단어 수 보존, 첫 풀이 안내, 생성 시점 조정. L3 개발 환경 회귀와 독립 검수 3회. 세 마켓과 서비스 공개까지.
- 추가 시각 요청: 기존 민트색 재사용 시안을 게임 느낌이 있는 시안으로 다시 비교한다. 이후 해외 진출을 고려한 문구 길이, 글자와 입력 구조도 설계에 반영한다.
- 현재 상태: 기능 설계와 테스트 계획 승인, UI 시안 2의 A 타일 보드 선택. 전체 판의 기본 입력을 음절 타일로 구체화한다.

기존 설계 본문의 “전면적인 아트 교체는 포함하지 않는다”와 “기존 앱의 서체, 민트 색상”은 이번 추가 시각 요청으로 변경 대상이 되었다. 기능 정책, 보상과 광고 규칙, 검수 등급과 출시 범위는 그대로 유지한다. 선택한 방향을 기준으로 화면 외형을 구현한다. 이번 요청만으로 해외 언어 콘텐츠 제작이나 새 국가 출시를 완료로 간주하지 않는다.

실행 이슈: [#435](https://github.com/seorilabs/crossword-puzzle/issues/435)

- 날짜: 2026-10-23
- 사용자 선택: “A 시안은 괜찮다.”
- 기준: `4170abdad5db7ad111702420f12a95736ce2c477`의 UI 시안 2, A 타일 보드. 비교 렌더는 `ui-v2/artifacts.md`의 검증된 NAS 원본을 따른다.
- 추가 요청: “이번에 집중적으로 점검해야할게 입력 용이성이다. 밑에서 키보드가 올라오는게 생각보다 불편하던데 이거 모바일에서 편하게 해주려면 어떤 방법이 좋을까? 아이디어 좀 내봐.”
- 이 메시지에서는 A의 외형만 선택했다. 당시 비교는 [입력 편의 개선 후보](input-usability-options.md)에 기록했다. 아래 후속 요청에서 음절 타일을 기본 입력으로 구체화한다.

## 전체 판 음절 타일 방향

- 사용자 후속 지시: “차라리 음절 타일 선택하는게 어때? 난이도는 낮게 해주고 게임 한판을 잘 완성할 수 있게 해주는거지”
- 반영 범위: 첫 세 단어 보조에 한정하지 않고, 오늘 판 전체의 기본 입력을 음절 타일로 정리한다. 앞선 시스템 키보드 중심의 추천을 대체한다.
- 상세안: [한 판 완성을 돕는 음절 타일 입력](syllable-tile-input.md). 후보 수와 오답 복구 등은 이 요청을 구체화한 설계값이며 실제 구현과 검수 결과는 별도로 남긴다.
- 보존: A 외형, 큰 판과 전체 출제 후보, 한 판의 단어 수, L3 개발 환경 회귀와 독립 검수 3회, 기존 세 마켓 및 서비스 공개 범위.
- 테스트 계획에는 `syllable-tile-input`을 추가하고, 이미 승인된 등급과 환경, 기준 버전 및 출시 끝 지점은 낮추거나 바꾸지 않는다.
