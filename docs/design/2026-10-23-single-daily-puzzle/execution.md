# 구현과 실행 상태

승인 기록과 뒤이은 A 외형, 음절 타일, 고정 배치 확인은 [approval.md](approval.md)를 따른다. 설계 본문의 이전 입력과 외형 설명은 이 후속 승인으로 변경되었다.

## 생성 서비스

- 전체 원본 24,963단어를 수정하거나 삭제하지 않았다. 원본 SHA-256은 `8602e7462c3ce216ba34de9d4f9139a040e4afea30e3d08f9f6c81197299a946`이다.
- 초급 128, 중급 32, 고급 1, 등급 없음 1의 추첨 가중치와 익숙한 어휘를 우선하는 탐색 점수를 사용한다. 정답과 어근 제한, 보드 품질 기준은 낮추지 않았다.
- 단일 판은 8×8, 최소 20단어다. `vocabularyLevel`을 답안의 출처와 함께 전달해 첫 3단서 추천에서도 같은 정보를 사용한다.
- `--single-daily-from`과 `PUZZLE_SINGLE_DAILY_FROM_DATE`로 전환을 명시한다. 기본 생성 시각은 23:00, 공개 시각은 다음 날짜 자정이다. 이미 발행한 ID, 최초 전환 날짜와 과거 두 판은 보존한다.
- 발행 전에 공개본 점검 URL을 확인하고 발행 뒤 대상 날짜를 실제 health 코드로 점검한다. 설정이 없으면 발행 전에 중단한다.

## 확인 범위

단일 공개 시각, 시간대와 일광 절약 시간, 전환 전후 필요 판 수, 기존 식별자, 실제 Job 인자, setup dry-run과 입력 오류를 자동 검사했다. 30일 비교는 동일한 공개 manifest와 정답 이력 사본, 날짜별 seed를 사용해 로컬 출력만 만든다. 조정 중 결과와 최종 후보 실행은 구분하며, 최종 후보의 30일 비교와 독립 전체 회귀 전에는 출시 검수 통과로 기록하지 않는다.

생성 서비스의 실제 설정 변경과 공개는 아직 수행하지 않았다. 현재 등록 CLI identity에서 대상 프로젝트의 Job과 Artifact Registry 조회 권한이 거부되어 live 구성 확인이 남아 있다. 코드의 모의 공급자 검사나 dry-run은 운영 설정 적용 증거가 아니다.

## 원본 보관

실행 로그와 30일 각 판 원본은 작업 산출물 폴더에서 유지한다. 최종 검수 뒤 NAS1dual로 복사하고 크기와 SHA-256을 직접 대조한 보관 목록을 이 문서에 연결한다. 아직 이관 완료로 기록하지 않는다.
