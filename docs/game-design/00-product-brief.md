## 제품 계약

현재 앱의 핵심인 `한국어 단서를 읽고 교차 글자로 답을 추론하는 즐거움`은 보존한다. 새 제품은 정답을 입력할 때 격자만 채우는 도구형 화면을 넘어, 끊긴 말길이 이어지고 작은 세계가 되살아나는 2D 어드벤처 퍼즐 게임으로 재구축한다.

한 줄 약속은 다음과 같다.

> 낱말을 풀어 끊긴 길을 잇고, 매일 하나의 작은 세계를 되살린다.

엔진 전환의 이유는 장식 추가가 아니다. 단어 완성, 교차점 연쇄, 보드 완료가 각각 길의 점등, 캐릭터 이동, 종이 모형 세계의 복원으로 이어져 퍼즐의 논리 구조 자체가 장면의 원인이 되어야 한다.

기존 Obsidian source snapshot은 `프로젝트/개인/가로세로낱말퍼즐/01 기획서.md`, updated `2026-07-17`, SHA-256 `bea82084742faeb88e7229c63b92acdb375bed2103a3f6d34af628f6dac970be`다. 이 snapshot에는 `DEC-015` 승인과 native Firebase 설정 추적 정리 메모가 동기화되어 있고, 나머지 게임화 제안은 아직 기존 본문을 덮어쓰지 않는다.

## 플레이어 판타지와 제품 기둥

플레이어는 잊힌 낱말을 복원하는 `말길 안내자`다. 단어를 맞히면 해당 답이 놓인 길이 살아나고, 교차점이 연결될수록 작은 주민과 풍경이 움직인다.

1. **추론이 곧 세계 변화**: 정답과 교차 구조가 장면 복원의 직접 원인이다.
2. **한국어 콘텐츠 신뢰**: 모든 단서는 사람이 검수하고 출처, 짧은 설명, 오류 제보 경로를 제공한다.
3. **첫 성공까지 마찰 최소화**: 첫 홈 화면, 계정, 광고, 알림 동의보다 첫 단어 성공을 먼저 준다.
4. **차분하지만 손맛 있는 연출**: 타이머와 생명 차감 없이도 잉크 흐름, 길 연결, 캐릭터 이동으로 즉각 보상한다.
5. **세 시장 하나의 게임**: 동일한 코어와 콘텐츠를 AIT, Android, iOS에서 유지한다.

## 범위

### Phase 0: 결정용 수직 슬라이스

- 실제 한국어 퍼즐 1개, 한글 조합 입력, 단어·교차·보드 완료 연출
- 동일 콘텐츠의 AIT 샌드박스, Android 실기기, iPhone 실기기 실행
- 로컬 저장과 복귀, 광고 1종의 pause/resume, Remote Config 1개
- VoiceOver와 TalkBack 대체 탐색, 축소 보드의 단어 집중 보기
- 운영 퍼즐팩의 수동 단서와 배포 버전 무결성 검증
- `ko-KR` 실제 퍼즐과 future-locale synthetic fixture가 같은 locale port·schema·저장 경계를 통과하는지 검증

### 출시 최소 범위

- `ko-KR` 첫 실행 3개, 챕터 30개, 일일 runway 42개, 주 2회 보너스 12개, 주간 도전 6개로 총 93개 검수 보드
- 지도 홈, 퍼즐, 결과 복원, 컬렉션, 기록, 설정, 오류 복구 화면
- 한글 직접 입력, 쉬운 입력 보조, 단계형 힌트, 자동 저장, 오프라인 재개
- 선택형 보상 광고, 꾸미기용 소프트 재화, 퍼즐 완료 기반 지도 진행
- 분석, Remote Config, 오류 제보, 콘텐츠 라이선스 원장

### 출시 후 후보

- 주간 협력 목표, 친구 기록 비교, 계정 기반 기기 이전
- 계절 지도, 신규 안내자, 테마별 지식 카드 세트
- 별도 word bank·단서 편집·난이도·라이선스·QA를 갖춘 후속 언어 pack
- 충분한 주간 신규 콘텐츠가 확보된 뒤 광고 제거 상품 검토

### 제외 범위

- 실시간 대전, 확률형 보상, 에너지·생명 대기, 퍼즐 진행을 막는 결제
- 3D 자유 이동, 물리 기반 전투, 사용자 제작 단서 공개 플랫폼
- 첫 세션 광고, 강제 계정, 게임 시작 전 Game Center 프로필 요구

## 제작 제약과 팀

- 현재 저장소의 순수 TypeScript 정책은 `packages/crossword-core`가 소유한다. 엔진이 이 계약을 우회하면 안 된다.
- 현재 AIT는 Vite/React, Android/iOS는 React Native로 출시 경로가 분리되어 있다. 전환 기간에는 기존 앱을 유지하고 새 런타임이 세 시장 게이트를 통과한 뒤 교체한다.
- 한국어 IME와 보조기술 접근은 엔진 캔버스만으로 해결하지 않고 DOM 또는 native 접근성 계층을 함께 사용한다.
- UI 문구는 안정 key catalog로, 정답·단서·해설은 locale별 content pack으로 분리한다. 장식 이미지에 번역 대상 문구를 굽지 않는다.
- 소규모 팀 가정은 클라이언트 1명, 게임 디자인·콘텐츠 1명, 파트타임 아트·오디오 1명, 파트타임 QA 1명이다. 실제 가용 인력이 이보다 작으면 보드 수를 줄이는 대신 콘텐츠 품질 게이트를 낮추지 않는다.
- 아트 생성 도구를 사용해도 최종 에셋은 사람이 스타일, 해상도, 상표·저작권, 손가락 가독성을 검수한다.

## 성공과 중단 기준

현재 GA4 표본은 작으므로 아래 지표는 소프트론칭 신규 설치 코호트 500명 이상에서 판단한다.
Crash·ANR·save 수치는 BLK-OBS-001의 시장별 source와 분모가 구현된 뒤에만 판정한다.

| 단계      | 성공 기준                                             | 중단 또는 재설계 기준                                       |
| --------- | ----------------------------------------------------- | ----------------------------------------------------------- |
| 활성화    | 신규 이용자 첫 입력 도달률 80% 이상, 중앙값 20초 이하 | 두 차례 수정 뒤 첫 입력 도달률 65% 미만                     |
| FTUE      | 첫 보드 완료율 70% 이상, 중앙 완료 3분 이하           | 완료율 55% 미만 또는 입력 오류 2% 이상                      |
| 핵심 퍼즐 | 도전 시작 대비 보드 완료 이용자 비율 55% 이상         | 콘텐츠 오류 제보가 완료 100건당 1건 초과                    |
| 잔존      | D1 18% 이상, D7 7% 이상                               | 코호트 500명 이상에서 D1 10% 미만이 2회 연속                |

| 품질      | crash-free user 99.5% 이상, 진행 저장 성공 99.9% 이상 | 진행 소실 재현 또는 세 시장 정책 불일치                     |
