## 론칭 결정

1차 AIT 론칭은 1번 방식으로 진행한다. 앱 홈에는 짧은 출처 고지를 노출하고, `/license` 화면에서 한국어기초사전 출처와 `CC-BY-SA-2.0-KR` 조건을 확인할 수 있게 한다.

출처/라이선스 표시는 Remote Config로 끄고 켜는 운영값이 아니다. 법적/검수 고지는 앱 안에 항상 접근 가능한 정적 UI로 둔다. 힌트 자체 문장 재작성은 라이선스 회피가 아니라 후속 품질 개선 항목으로 관리한다.
